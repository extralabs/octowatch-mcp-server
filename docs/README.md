# Documentation (octowatch-mcp)

MCP-specific docs for the **octowatch-mcp** server. This repository documents how to install and use the MCP bridge — not the full OctoWatch product or REST catalog.

## Product & console (canonical)

| Link | Role |
|------|------|
| [octowatchdlp.com](https://octowatchdlp.com/) | Product home |
| [octowatchdlp.com/docs/](https://octowatchdlp.com/docs/) | Product documentation |
| [app.octowatchdlp.com](https://app.octowatchdlp.com/) | Web Console |
| [app.octowatchdlp.com/api/](https://app.octowatchdlp.com/api/) | In-app interactive API catalog |

Repo docs **link out** to those sources. Do not treat `docs/API.md` as a second Help/`/api/` mirror.
